PenguinCSS

Github

About

PenguinCSS is a micro-CSS framework which provides components in the style of the Club Penguin UI.

So far there are basic buttons and cards in blue and orange, but I hope to add more components and styles soon.

Usage

Copy the classes from any example below into your markup. Each element comes in a blue and an orange flavour.

Elements

Buttons

<button class="pg-btn pg-btn-blue">
    Play Now
</button>
<button class="pg-btn pg-btn-orange">
    Play Now
</button>
